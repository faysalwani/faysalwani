### 🧠 NeuroSleep AI

**End-to-End Sleep-Health Risk Classification**

A machine-learning system that analyzes lifestyle, physiological, and behavioral features to classify sleep-health risk.

**Built with:**

`Python` `Scikit-learn` `XGBoost` `LightGBM`  
`SHAP` `SMOTE` `Pandas` `FastAPI` `React`

**Highlights**

- 📊 100,000+ records
- 🧬 Standard & advanced prediction engines
- 🌲 Random Forest + XGBoost + LightGBM ensemble
- ⚖️ SMOTE for class balancing
- 🔍 SHAP-based model explainability
- 🔄 Separate training and inference pipelines
- ⚡ FastAPI backend
- 🌐 React frontend

> Project evaluation achieved approximately **92% accuracy and 92% F1-score** for the advanced prediction engine.

[🔗 View Repository](https://github.com/faysalwani/nerosleep)
